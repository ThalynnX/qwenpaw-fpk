QwenPaw v2.2.3b1

本地优先的个人 AI 助手 · 飞牛 fnOS 原生直装版（非 Docker）

本应用基于 AgentScope 团队开源的 QwenPaw（Apache-2.0）构建，由 ThalynnX 打包适配 fnOS。

功能概览

  • 多通道对话：钉钉、飞书、QQ、Discord、Telegram 等
  • 多智能体协作：独立配置、记忆与技能，互相通信完成复杂任务
  • 定时任务与 Skills 扩展，能力可无限扩展
  • 支持对接本地 Ollama，完全离线工作
  • 数据全在本地，不依赖第三方托管

开始使用

Web 控制台：点击应用中心中「QwenPaw」入口即可打开（地址 http://NAS:19091）。

初始化：安装时已自动执行 qwenpaw init，默认配置可直接使用；如需修改渠道与模型， 在 NAS 终端执行：

docker 无需——直接进入应用目录：cd /var/apps/com.thalynnx.qwenpaw/target && sudo -u <app用户> /bin/bash -c "source ../home/venv/bin/activate && python3 -m qwenpaw init"

模型对接：Ollama 请先在应用商店安装 Ollama 应用，然后在控制台配置模型地址。

数据位置：授权目录下的 .qwenpaw（卸载保留，重装可恢复）。
